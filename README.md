# Hantavirus Maps

Source-linked public health map and reviewed tracker for `hantavirusmaps.org`.

The site is a static Next.js export deployed to Cloudflare Workers assets. It focuses on two primary SEO/user intents:

- `hantavirus map` — geography, state/region context, official sources, reservoir ecology, prevention.
- `hantavirus tracker` — reviewed official alerts, historical case summaries, source limitations, and safe interpretation.

It is intentionally **not** a live infection tracker, patient-location map, medical diagnosis tool, emergency service, or exact local/county risk score.

## Public-health / YMYL boundaries

Keep these constraints intact when editing copy or data:

- Do not claim real-time infection tracking.
- Do not claim live cases near the user.
- Do not publish exact patient locations.
- Do not imply CDC county-level case precision where public sources do not support it.
- Do not convert reservoir range into exact human risk.
- Do not present news/social signals as confirmed cases.
- Do not provide medical diagnosis, emergency guidance, treatment advice, or case reporting.
- Always distinguish:
  - reviewed case summaries
  - official public health alerts
  - reservoir/ecology context
  - prevention guidance
  - unreviewed/news signals

## Validation

Run before every deploy:

```bash
npm run lint
npm run build
```

The app uses Next.js static export and writes production assets to `out/`.

Important build note: the build script uses webpack:

```bash
npm run build
# next build --webpack
```

This avoids a Turbopack environment/port-permission panic previously seen in this workspace.

## Deploy to Cloudflare Workers

```bash
source /root/.openclaw/workspace-potter-dev/.env
npm run lint
npm run build
wrangler deploy
```

Worker name: `hantavirus-maps`

Custom domains:

- `hantavirusmaps.org`
- `www.hantavirusmaps.org`

Cloudflare deploy config is in `wrangler.toml`.

## GitHub Actions

Pushes to `main` trigger `.github/workflows/deploy.yml`:

1. `npm ci`
2. `npm run lint`
3. `npm run build`
4. `wrangler deploy`

Known warning: GitHub Actions currently warns that Node.js 20 actions are deprecated for `actions/checkout@v4`, `actions/setup-node@v4`, and `cloudflare/wrangler-action@v3`. Future maintenance should test/update the workflow for Node.js 24 compatibility before GitHub enforcement.
